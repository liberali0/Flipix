## What changed
- **앱 안에서 업데이트**: 새 버전이 나오면 Workshop 위쪽에 업데이트 단추가 나타납니다. 우클릭만 쓰는 경우에도 하루에 한 번 화면 오른쪽 아래에 알려 줍니다. 상세 설정에서 끌 수 있습니다.
- **업데이트만 진행**: 이미 설치돼 있으면 설치 위치를 묻지 않고 "업데이트" 화면(지금 버전 → 새 버전)만 보여 줍니다. 설치 위치와 설정은 그대로입니다.
- **수정 메뉴**: Windows 설정 > 앱 > Flipix의 [수정]으로 복구하거나 설치 위치를 바꿀 수 있습니다.
- **Workshop ⋯ 메뉴**: 상세 설정, 업데이트 확인, 바탕 화면 바로 가기 만들기.
- **변환 결과 알림**: 우클릭 변환이 끝나면 실패한 파일이 있을 때만(기본) 또는 항상 알려 줍니다.
- **우클릭 메뉴 아이콘**.
- **GIF 변환**: 첫 프레임만 또는 모든 프레임을 각각 파일로 저장할 수 있습니다.
- **크기 줄이기**: 최대 크기(비율 유지) 또는 비율(%)로 줄입니다. 원본보다 키우지는 않습니다.
- **Windows 11 ARM64 PC 지원**.
- **영어 화면**: Windows 표시 언어를 따르고, 상세 설정에서 한국어/English를 고를 수 있습니다.
- **고정 서명**: 이번 버전부터 같은 인증서로 서명해서, 업데이트 때마다 뜨던 관리자 확인이 처음 한 번만 뜹니다.
- **이름 정리**: 프로그램 파일과 기본 설치·설정 폴더 이름을 Flipix로 바꿨습니다. 기본 폴더에 설치돼 있었다면 업데이트할 때 설정과 함께 자동으로 옮겨집니다.
- **깔끔한 제거**: 제거하면 "직접 지우세요" 안내 없이 프로그램과 설정이 모두 지워집니다.

v0.1.4 이하에서는 이번 한 번만 설치 파일을 직접 받아 실행해 주세요. 그다음부터는 앱 안에서 업데이트됩니다.

## What changed
- **In-app updates**: when a new version is out, an update button appears at the top of Workshop. If you only use the right-click menu, a small notice in the lower-right corner tells you once a day. You can turn this off in Advanced settings.
- **Update only**: if Flipix is already installed, setup skips the install questions and shows a single "Update" screen (current version → new version). Your install folder and settings stay the same.
- **Modify**: use [Modify] for Flipix in Windows Settings > Apps to repair it or move the install folder.
- **Workshop ⋯ menu**: Advanced settings, Check for updates, Create desktop shortcut.
- **Result notice**: after a right-click convert, Flipix tells you only when a file fails (default) or every time.
- **Icon in the right-click menu**.
- **GIF conversion**: save only the first frame, or every frame as its own file.
- **Resize**: shrink to a max size (keeping the aspect ratio) or by a percentage. Images are never enlarged.
- **Windows 11 ARM64 PC support**.
- **English UI**: follows the Windows display language. You can choose 한국어 or English in Advanced settings.
- **Stable signing**: from this version on, releases are signed with the same certificate, so the administrator prompt shown on every update appears only once.
- **Name cleanup**: program files and the default install and settings folders are now named Flipix. If Flipix was in the default folder, the update moves it there along with your settings.
- **Clean uninstall**: uninstalling removes the program and its settings completely, without asking you to delete leftovers by hand.

If you have v0.1.4 or earlier, download and run the installer yourself this one time. After that, Flipix updates itself from inside the app.
